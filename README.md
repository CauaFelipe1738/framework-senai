# Front-end

A disciplina de Front-end tem como objetivo a criação de aplicações web utilizando frameworks front-end.

## Tecnologias utilizadas

<ul>
  <li>Vue</li>
  <li>Angular</li>
  <li>React</li>
  <li>Express.js</li>
  <li>Node JS</li>
</ul>
