# Atividade 01

## Resumo da proposta

O objetivo desta atividade é desenvolver uma aplicação web simples utilizando **Vanilla JavaScript**, sem frameworks, empregando apenas as tecnologias fundamentais da web:

- **HTML** para estruturar a página;
- **CSS** para estilizar a interface;
- **JavaScript** para implementar a lógica da aplicação.

Após o desenvolvimento, o projeto deverá ser integrado ao **GitHub** por meio da IDE utilizada e, por fim, publicado na **Vercel**, tornando a aplicação acessível pela internet.

A atividade pode ser acessada pelo deploy do [vercel](https://atv1-front-2026-sem2.vercel.app/) ou pelo [repositório do Github](https://github.com/CauaFelipe1738/atv1-front-2026-sem2)

# Solução Proposta

## Tema
**Site que aparece texto ao clicar num botão**

### Descrição

A aplicação consiste em um site simples que exibe um texto predefinido sempre que o usuário clicar em um botão. Os textos são armazenados em um vetor no JavaScript e escolhidos ordenadamente a cada clique.

### Funcionalidades

- Interface simples;
- Botão para gerar um novo texto;
- Exibição de frases predefinidas;
- Utilização apenas de HTML, CSS e JavaScript (Vanilla JS);
- Hospedagem do projeto na Vercel.

### Estrutura do Projeto

```text
projeto/
│
├── index.html
├── style.css
├── script.js
```

### Funcionamento

1. O usuário acessa a página.
2. Um botão **"Botão de summon"** é exibido.
3. Ao clicar no botão, o JavaScript seleciona uma frase.
4. O texto é mostrado na tela.
5. A cada novo clique, uma nova frase pode ser exibida.

### Objetivos de Aprendizagem

- Praticar a estruturação de páginas com HTML;
- Aplicar estilos utilizando CSS;
- Manipular eventos e o DOM com JavaScript;
- Utilizar Git e GitHub para versionamento;
- Realizar o deploy da aplicação utilizando a Vercel.

### Resultado Esperado

Ao final da atividade, será entregue uma aplicação web funcional, publicada na internet, demonstrando conhecimentos básicos de desenvolvimento front-end, controle de versão e implantação de projetos.
