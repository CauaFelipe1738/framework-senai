# Organização do repositório raiz
A atividade propõe que o repositório onde as atividades da disciplina front-end são realizadas (nesse caso, framework-senai) deve ser organizada para ter uma boa apresentação visual.

## Objetivos
Em alinhamento com o mercado de trabalho, o Github e os projetos criados pelas pessoas são usados como portfolios para empregadores da área de TI. Dessa forma, os repositórios devem ter uma boa apresentação.

## Solução proposta
Entre as mudanças feitas, foram criado um README com uma descrição breve da disciplina e das atividades feitas. As atividades foram organizadas e formatados em arquivos markdown com descrições e links.
