# Descrição básica
Nesta atividade, deve se criar um projeto usando Express.js, criando uma API e a consumindo para mostrar suas infomações na tela do usuário.

## Solução proposta
Para realizar o projeto, a criação de APIs foram feitas [neste repositório](https://github.com/CauaFelipe1738/atv-aula4-2026-2back), enquanto a aplicação visível ao usuário foi desenvolvida em um [repositório separado](https://github.com/CauaFelipe1738/atv-aula4-2026-2). 
Para deploy, as APIs foram implementadas na plataforma [Render](https://atv-aula4-2026-2back.onrender.com/), e a aplicação na [Vercel](https://atv-aula4-2026-2.vercel.app/).

## Objetivos de Aprendizagem
- Criação e configuração de ambientes Express.js
- Configuração de projetos que consomem APIs
- Criação de APIs
- Deploy de APIs

## Resultado esperado
Ao acessar a [plataforma implementada](https://atv-aula4-2026-2.vercel.app/), o site deve devolver uma resposta com a data e horário no presente.
