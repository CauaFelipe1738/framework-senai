A atividade consiste no desenvolvimento de uma aplicação React utilizando o Visual Studio Code. O projeto terá um botão que, ao ser clicado, fará um texto aparecer na tela. Após o desenvolvimento, o código deverá ser versionado com Git e enviado para um repositório no GitHub. Por fim, o projeto será publicado na Vercel, permitindo que a aplicação fique disponível online por meio de uma URL pública.
